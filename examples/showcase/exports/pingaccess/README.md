# PingAccess in front of Tech Pubs (synthetic)

Made-up PingAccess 8.3.6 Admin API v3 responses, saved as `opsdir collect --adapter pingaccess/admin-api` saves them (`<collection>/page-<n>.json`, settings objects as `<path>.json`), in the shapes Ping's documentation describes (unverified for 9.1.1: see the adapter's README). PingAccess protects the Tech Pubs application (`techpubs.example-aero.test`): its web session signs users in with PingFederate's client `tech-pubs-web` (issuer `https://sso.example-aero.test`) and tells the application who they are in `X-TechPubs-User`; the media application is served from a CDN reached at the same host from every environment. The demo reads it with `opsdir import --change CHG-2061 pingaccess/admin-api exports/pingaccess`; the client secret is a hidden field, withheld whole (its ciphertext is never stored).
