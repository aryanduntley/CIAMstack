# The PingAccess servers' own files (synthetic)

Made-up copies of the source's PingAccess servers' files (one folder per server, named by its hostname, at their paths under /), laid out as in `exports/hosts`. They're read after CHG-2060 records the servers: `opsdir import --change CHG-2075 linux/baseline exports/hosts-pingaccess` records the `pa-admin` and `pa-engine` host baselines from the admin node and both engines. That covers the OS, Java (`java -version`) and its truststore (`keytool -list -cacerts`), limits, sysctl, huge pages, FIPS and SELinux modes, `packages.txt` (`rpm -qa`), the `pingaccess` service unit, `/etc/hosts` and `resolv.conf`. Like the PingFederate servers, their truststore adds the corporate root CA (the certificate CHG-2013 records), and they run the AWS agents, which CHG-2076 moves to baselines scoped to AWS environments.
